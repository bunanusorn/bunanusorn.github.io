1 วงจรการประมวลผลข้อมูล (IPO Cycle: Input - Process - Output)

หลักการวิเคราะห์ระบบงานธุรกิจทุกประเภท ต้องแยกแยะข้อมูลนำเข้า ขั้นตอนประมวลผล และผลลัพธ์ให้ชัดเจน

2 สัญลักษณ์ผังงาน (Flowchart) มาตรฐาน ANSI / ISO

สัญลักษณ์พื้นฐานที่นักเขียนโปรแกรมต้องใช้สื่อสารขั้นตอนการทำงาน (Algorithm)

จุดเริ่มต้น / สิ้นสุด (Terminator)

แสดงจุดเริ่มต้นและจุดสิ้นสุดของผังงาน

การประมวลผล (Process)

การคำนวณ การกำหนดค่าตัวแปร

การตัดสินใจ (Decision)

ตรวจสอบเงื่อนไข จริง (True) / เท็จ (False)

รับข้อมูล / แสดงผล (I/O)

รับค่าทางแป้นพิมพ์หรือแสดงผลหน้าจอ

จุดเชื่อมต่อในหน้า (Connector)

เชื่อมเส้นผังงานในหน้ากระดาษเดียวกัน

เส้นทิศทาง (Flowline)

บอกทิศทางการไหลของลำดับการทำงาน

ตัวอย่างรหัสเทียม (Pseudocode) มาตรฐานสากล

BEGIN
    INPUT product_price, quantity
    SET subtotal = product_price * quantity
    SET vat = subtotal * 0.07
    SET grand_total = subtotal + vat
    PRINT "ยอดสุทธิที่ต้องชำระ = ", grand_total
END

1 ตัวแปร (Variable) และชนิดข้อมูลพื้นฐาน (Data Types)

ให้จินตนาการว่า "ตัวแปร" คือ "กล่องเก็บของในหน่วยความจำ" ที่ต้องติดป้ายชื่อและเลือกขนาดกล่องให้ตรงกับข้อมูล

Integer (int)

จำนวนเต็ม

เช่น จำนวนสินค้า qty = 15

Float / Double

เลขทศนิยม

เช่น ราคา, ภาษี price = 199.50

String (str)

ข้อความตัวอักษร

อยู่ในเครื่องหมายคำพูด "..."

Boolean (bool)

ค่าความจริง

มีแค่ 2 ค่าคือ True / False

ตัวแปลภาษาคอมพิวเตอร์ (Translator)

โครงสร้างสูตรคำนวณใบเสร็จ & VAT 7%

# โครงสร้างการทำงานแบบลำดับ (Sequence)
subtotal = price * quantity
vat = subtotal * 0.07 # ภาษีมูลค่าเพิ่ม 7%
net_total = subtotal + vat
print(f"ยอดสุทธิ: {net_total:,.2f} บาท")

1 แผนภาพผังงานโครงสร้างเงื่อนไขหลายทางเลือก (Nested If / Elif)

ตัวอย่างตรรกะการคำนวณส่วนลดการค้าแบบขั้นบันไดตามนโยบายธุรกิจ

1. Syntax Error

เขียนผิดไวยากรณ์ภาษา เช่น ลืมใส่เครื่องหมาย : หรือสะกดคำสั่ง pritn() ผิด โปรแกรมจะรันไม่ได้

2. Runtime Error

โปรแกรมพังระหว่างทำงาน เช่น นำตัวเลขไปหารด้วยศูนย์ (10 / 0) หรือกรอกตัวอักษรในช่องตัวเลข

3. Logic Error

โปรแกรมรันจบปกติแต่ คำตอบผิด! เช่น ใช้เครื่องหมาย < แทน > ต้องใช้ Debugger ตรวจสอบ

1 โครงสร้างการทำงานแบบวนซ้ำ (Looping) & ตัวแปรสะสมค่า (Accumulator)

ใช้สำหรับงานบัญชีรับ-จ่ายต่อเนื่อง และระบบตรวจสอบสต็อกสินค้าคงคลังอัตโนมัติ

แนวคิดจุดสั่งซื้อซ้ำ (Reorder Point)

ในการเขียนโปรแกรมสต็อกสินค้า เราจะใช้คำสั่งวนซ้ำ (Loop) ตรวจสอบสินค้าทุกชิ้นในคลัง หากพบว่า stock <= reorder_point ระบบจะขึ้นแจ้งเตือนให้สั่งซื้อเพิ่มทันที!

1 โครงสร้างแถวลำดับ (Array / List) และการอ้างอิงดัชนี (Index)

ตัวแปรชุดที่เก็บข้อมูลชนิดเดียวกันเรียงต่อกัน โดยตำแหน่ง Index แรกในคอมพิวเตอร์จะเริ่มนับที่ 0 เสมอ!

2 การทำงานของฟังก์ชันย่อย (Function, Parameter & Return)

ฟังก์ชันเปรียบเสมือน "เครื่องจักรอัตโนมัติ" ที่รับวัตถุดิบ (Parameter) เข้าไปคำนวณ แล้วส่งผลลัพธ์ (Return) กลับออกมาใช้งานซ้ำได้

1 การจัดการแฟ้มข้อมูลถาวร (File Handling: CSV) & Exception Handling

ข้อมูลในตัวแปร RAM จะหายไปเมื่อปิดโปรแกรม จึงต้องบันทึกลงไฟล์ถาวร (.csv) พร้อมมีเกราะป้องกัน Error ด้วย Try-Catch
