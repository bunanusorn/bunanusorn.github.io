เจาะลึกเรื่อง Subnet Mask และการแบ่งเครือข่ายย่อย (Subnetting)

ศึกษาเนื้อหาทั้ง 5 หัวข้อด้านล่างให้เข้าใจ พร้อมทดลองใช้เครื่องมือจำลองการแปลงเลขฐานสองก่อนเข้าสู่แบบฝึกปฏิบัติ

1

ความหมายและหน้าที่ของ Subnet Mask

Subnet Mask (ซับเน็ตมาสก์) คือชุดตัวเลขขนาด 32 บิต (แบ่งเป็น 4 ชุด ชุดละ 8 บิต หรือ 4 Octets เช่นเดียวกับ IPv4 Address) ที่ทำหน้าที่เป็น "ตัวกรอง" เพื่อแยกแยะว่าส่วนใดของหมายเลข IP Address คือ หมายเลขเครือข่าย (Network Portion) และส่วนใดคือ หมายเลขเครื่องลูกข่าย (Host Portion)

บิต 1 ส่วนของเครือข่าย (Network Portion)

ตำแหน่งที่ Subnet Mask มีค่าบิตเป็น 1 จะบอกให้อุปกรณ์เครือข่ายทราบว่าบิตในตำแหน่งเดียวกันของ IP Address คือ รหัสเครือข่าย (Network ID) อุปกรณ์ที่อยู่ในวง LAN เดียวกันจะต้องมีส่วนนี้เหมือนกันทั้งหมด

บิต 0 ส่วนของโฮสต์ (Host Portion)

ตำแหน่งที่ Subnet Mask มีค่าบิตเป็น 0 จะบอกว่าเป็น หมายเลขประจำตัวเครื่อง (Host ID) ซึ่งใช้กำหนดให้กับคอมพิวเตอร์ สมาร์ทโฟน หรืออุปกรณ์ต่าง ๆ ภายในเครือข่ายนั้น ๆ โดยต้องไม่ซ้ำกัน

2

Default Subnet Mask ของ IP Class A, B, C และระบบ CIDR

ในการแบ่ง IPv4 แบบดั้งเดิม (Classful Addressing) จะกำหนดค่า Subnet Mask เริ่มต้นตามคลาสของ IP แต่ในปัจจุบันนิยมใช้ระบบ CIDR (Classless Inter-Domain Routing) ซึ่งเขียนแทนด้วยเครื่องหมายทับตามด้วยจำนวนบิต 1 เช่น /24 เรียกว่า Prefix Length

คลาส (Class) ช่วง IP Octet แรก Default Subnet Mask CIDR รูปแบบเลขฐานสอง จำนวน Host สูงสุด
Class A 1 – 126 255.0.0.0 /8 11111111.00000000.00000000.00000000 16,777,214 เครื่อง
Class B 128 – 191 255.255.0.0 /16 11111111.11111111.00000000.00000000 65,534 เครื่อง
Class C 192 – 223 255.255.255.0 /24 11111111.11111111.11111111.00000000 254 เครื่อง
3

การแปลงเลขฐานสองเป็นฐานสิบ และตารางค่าประจำหลัก (8 บิต)

ในแต่ละ Octet ของ Subnet Mask มีจำนวน 8 บิต ซึ่งมีค่าประจำหลักเรียงจากซ้ายไปขวาคือ 128, 64, 32, 16, 8, 4, 2, 1 และมีกฎสำคัญคือ บิต 1 จะต้องเรียงต่อกันจากซ้ายไปขวาเสมอ ทำให้ค่าตัวเลขฐานสิบที่เป็นไปได้ในแต่ละ Octet ของ Subnet Mask มีเพียง 9 ค่าเท่านั้น คือ:

4

สูตรการคำนวณจำนวนเครือข่ายย่อย (Subnets) และจำนวนโฮสต์ (Hosts)

สูตรที่ 1: จำนวนเครือข่ายย่อย
2n

โดยที่ n คือ จำนวนบิตที่ยืมมา (Borrowed Bits) จากส่วนของ Host มาเป็น Network (เช่น จาก /24 ไป /26 ยืมมา n = 2 บิต จะได้ 22 = 4 เครือข่ายย่อย)

สูตรที่ 2: จำนวน Host ที่ใช้งานได้
2h - 2

โดยที่ h คือ จำนวนบิต 0 ที่เหลืออยู่ (h = 32 - CIDR) สาเหตุที่ต้อง ลบ 2 เพราะต้องสงวน IP แรกไว้เป็น Network ID และ IP สุดท้ายไว้เป็น Broadcast Address

สูตรที่ 3: ค่ากระโดด (Block Size)
256 - เลข Octet

นำ 256 ลบด้วยเลข Subnet Mask ใน Octet ที่มีการแบ่งย่อย (Interesting Octet) จะได้ระยะห่างของแต่ละ Subnet เช่น /26 (255.255.255.192) ค่า Block Size = 256 - 192 = 64

5

ตัวอย่างการคำนวณหา Network ID, First Host, Last Host และ Broadcast ทีละขั้นตอน

โจทย์ตัวอย่าง: จงวิเคราะห์ข้อมูลเครือข่ายของ IP Address 192.168.10.75 /26

ขั้นตอนที่ 1: หา Subnet Mask จาก /26

มีบิต 1 จำนวน 26 ตัว = 11111111.11111111.11111111.11000000 แปลงเป็นฐานสิบได้ 255.255.255.192

ขั้นตอนที่ 2: หา Block Size (ช่วงห่างของแต่ละ Subnet)

Octet ที่ 4 มีค่าเป็น 192 ดังนั้น Block Size = 256 - 192 = 64
จะได้ช่วง Network ID เรียงทีละ 64 คือ: .0, .64, .128, .192

ขั้นตอนที่ 3: ระบุช่วงที่ IP 192.168.10.75 ตกอยู่

เลข 75 อยู่ระหว่าง 64 ถึง 127 (ก่อนขึ้นวงถัดไปที่ .128) ดังนั้น:

  • Network ID (หมายเลขเครือข่าย): 192.168.10.64
  • First Usable IP (IP แรกที่ใช้งานได้): 192.168.10.65 (Network ID + 1)
  • Last Usable IP (IP สุดท้ายที่ใช้งานได้): 192.168.10.126 (Broadcast - 1)
  • Broadcast Address (หมายเลขบรอดแคสต์): 192.168.10.127 (Network ถัดไป - 1)
  • จำนวนโฮสต์ที่ใช้งานได้ทั้งหมด: 26 - 2 = 64 - 2 = 62 เครื่อง
